## Project Description
This project focuses on mastering core JavaScript DOM manipulation and event handling concepts. It includes exercises on element selection, traversal, content modification, dynamic element creation/removal, event handling, event propagation, delegation, and form validation.

---

## Technologies Used
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  

---

## Features
- DOM element selection using:
  - getElementById
  - querySelector
  - querySelectorAll
- DOM traversal:
  - parent, children, siblings navigation
- Content manipulation:
  - textContent, innerHTML
- Attribute handling:
  - getAttribute, setAttribute, dataset
- Dynamic styling via JavaScript
- Creating, inserting, cloning, and removing elements
- Event handling:
  - click, keyboard, form events
- Event object usage:
  - target, currentTarget, preventDefault
- Event bubbling demonstration
- Event delegation using a single parent listener
- Basic form validation with real-time feedback
- Dynamic navigation item creation

---

## How to Run
1. Clone this repository
2. Open `index.html` in your browser

## Lessons Learned
-Difference between HTML attributes vs DOM properties
-DOM updates are destructive by default
-Importance of event delegation for dynamic elements
-How event bubbling works
-Safe vs unsafe DOM manipulation (textContent vs innerHTML)
-Structuring code to avoid conflicts between multiple DOM operations

## Challenges Faced
-Elements returning null due to incorrect selectors
-Content disappearing due to multiple DOM overwrites
-Event delegation issues fixed using closest()
-Reusing DOM elements without cloning
-Form validation not triggering due to incorrect function structure
